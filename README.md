# LaiMue ลายมือ

Type Thai on a worksheet and it comes out in *your own* handwriting. Each person teaches the app their handwriting once; it stays on their device.

Open: https://thanaponrochanaphon.github.io/laimue/ — on iPad tap Share → Add to Home Screen.

Fallback font: Sriracha (SIL Open Font License, see lib/Sriracha-OFL.txt).
